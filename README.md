# IFT187
Matériel de cours de l’activité IFT187 — Éléments de bases de données — dispensée au Campus principal de l’Université de Sherbrooke au trimestre d’automne 2026.


## Structure du dépôt
* NDC : dossier contient les notes de cours
* PRE : dossier contient les présentations
* REF : dossier contient les références complémentaires aux notes de cours
* TD : dossier contient le matériel pour les travaux dirigés
